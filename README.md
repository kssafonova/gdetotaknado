# NORD — HS-порталы

Адаптивный React/Vite лендинг для продажи алюминиевых HS-порталов понятным для клиента языком.

## Что внутри

- премиальный responsive UI для desktop / tablet / mobile;
- большой объясняющий блок: как работает HS, порог, сценарии применения, профильные системы;
- короткий блок полного цикла работ;
- интерактивный калькулятор с ориентировочной ценой;
- секция проектов и бюджетов;
- trust-блок и FAQ;
- SEO: title/description, Open Graph, canonical, robots.txt, sitemap.xml, schema.org;
- доступные кнопки, anchor-navigation и мобильное меню;
- простой Node backend `POST /api/leads` для формы заявки;
- GitHub Pages workflow для статического демо.

## Запуск

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run serve
```

`npm run serve` раздаёт `dist` и принимает заявки в `server/data/leads.ndjson`.

## Перед боевой публикацией

1. Замените NORD на финальный бренд, телефон, email и юридические данные.
2. Замените демонстрационные карточки проектов на реальные объекты и фактические цены.
3. Проверьте коэффициенты калькулятора по реальному прайсу компании.
4. Для production подключите `/api/leads` к CRM/Telegram/email и добавьте согласие на обработку ПДн.
5. При переезде с GitHub Pages на основной домен обновите canonical, sitemap и `base` в Vite.

## Калькулятор

Демо-ставки лежат в `src/App.jsx`:

- рациональный — 75 000 ₽/м²;
- комфорт — 95 000 ₽/м²;
- максимум — 120 000 ₽/м².

Это ориентиры интерфейса, а не публичная оферта.
